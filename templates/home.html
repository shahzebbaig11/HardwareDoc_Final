How Backward Chaining Works

Backward chaining is a reasoning strategy used in rule-based expert systems. Instead of applying all available rules forward, the engine starts from a goal — the fault it wants to prove — and works backward to find the facts that would support that conclusion.

The engine selects rules whose THEN part matches the current goal. For each such rule, it recursively tries to prove every IF premise. If a premise cannot be derived from other rules, it asks the user.

Questions stop the moment a conclusion is proven, disproven, or no more useful questions remain. The engine handles multiple alternative rules and detects cyclic dependencies so it never loops infinitely.

Every answer is recorded in working memory. The final conclusion references the exact rules and facts that produced it — available as a HOW explanation after each diagnosis.

Goal fault_no_power
↓ matches rules
Rule R01 IF power_cable_disconnected THEN fault...
↓ premise unknown → ask user
Question Q02 Is the power cable plugged in?
↓ Answer: No
